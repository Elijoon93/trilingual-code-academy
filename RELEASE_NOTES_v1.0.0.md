# TriLingual Code Academy — v1.0.0 Stable

Release date: 2026-09-13

## Release scope
نسخه پایدار وب پس از عبور از ممیزی استاتیک، Syntax JavaScript، تست واقعی Chromium در GitHub Actions و Deploy موفق GitHub Pages منتشر شد.

## اصلاحات نهایی
- حذف کامل Loader سه‌تکه Base64 از مسیر اجرای اصلی.
- اصلاح Runtime Code Lab و closing tagهای `script` در iframe.
- حفظ Storage Key قبلی و مهاجرت Schema 13.
- Backup Format 3 با نمایش تاریخ جلالی.
- تقویم و تاریخ‌های رابط فارسی/Jalali.
- Responsive fixes مسیرهای English، Deutsch و Coding.
- Final Acceptance CI برای هر Push روی `main`.
- Chromium smoke برای routes، Planner، Code Lab و LocalStorage persistence.
- Service Worker با cache namespace نسخه Stable.

## Device certification
Windows و Android/PWA فیزیکی در خود برنامه قابل ثبت هستند. هیچ Device PASS بدون اجرای واقعی روی سخت‌افزار ثبت نشده است.
